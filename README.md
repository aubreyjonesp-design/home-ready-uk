# Home Ready UK

Calm, plain-English help for UK households: a 3-day kit and water calculator, a printable plan and short guides. It follows GOV.UK Prepare. Independent: not part of the UK Government.

- Static site, with no build step needed to serve it. Pages are generated by `python3 build.py`; edit that file, not the HTML.
- No cookies, trackers or external fonts.
- `launch/` holds the planning notes (smoke test, survey spec, hosting, share posts, approvals).
- **Private until the privacy notice placeholders are filled in.** GitHub Pages is not enabled yet.
